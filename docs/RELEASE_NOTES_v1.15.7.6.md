# 批量打印插件 v1.15.7.6 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。相对 **v1.15.7.5** 的更新如下。

## 相对 v1.15.7.5 的更新

### 通用型多文件排序

- 多文件清单先按文件名分组排序。
- 同一文件内识别到图号时按图号自然序；没有图号时仍按原来的布局与空间顺序。
- 图号和图名都相同的连续条目，再用空间顺序排开。

### 图框录入

- 外框识别增加四线拼合：块内浅层四条独立直线或开放多段线可拼成矩形，与闭合矩形按面积取最大。
- 字段框选对话框首次显示不再整图重生成，避免复杂图面白块、长时间卡顿。红色临时框仍会刷新。

### 矩形扫描

- 四线拼合与图框录入共用同一套算法和容差，扫描结果与录入外框的判定一致。

### 打印样式

- 点「设置」编辑 CTB/STB 时，中望和 AutoCAD 都向 `PlotConfigManager` 取样式表完整路径，不再手写 Plotters 目录。

### 界面

- 关于窗口去掉多余最小高度，按内容自适应。
